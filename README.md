## 📌 About The Project

StudyMate is a student-focused productivity application designed to help students manage their academic and personal activities from a single dashboard.

The application combines task management, expense tracking, study sessions, and productivity statistics into one simple and interactive interface.

The project was built using React and Vite, with browser LocalStorage used to persist user data.

---

## ✨ Features

### 📊 Dashboard

- View total tasks
- View completed tasks
- Track daily expenses
- Track study sessions
- View today's productivity progress
- Quick access to important features

### ✅ Task Management

- Add new tasks
- Add subject names
- Set task priority
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Track task completion percentage

### 💰 Expense Tracker

- Add expenses
- Categorize expenses
- Search expenses
- Filter expenses
- Delete expenses
- Track total spending
- Manage budgets

### ⏱️ Study Timer

- 15-minute study session
- 25-minute study session
- 50-minute study session
- Start timer
- Pause/stop timer
- Reset timer
- Track completed study sessions

### 📈 Statistics

- Overall task statistics
- Task completion percentage
- Tasks by priority
- Tasks by subject
- Expense statistics
- Spending by category
- Study session statistics
- Productivity overview
- Data export

### 🎨 User Interface

- Clean dashboard interface
- Sidebar navigation
- Dark mode / Light mode
- Responsive layout
- Interactive buttons
- Notifications and confirmation dialogs
